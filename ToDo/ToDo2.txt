Чтобы библиотека работы с интервалами была полной, предсказуемой и не заставляла пользователя писать костыли для типовых задач, функции делят на 4 функциональные группы (от базового ядра до прикладных операций).
Ниже — исчерпывающий чек-лист того, что обычно закладывают в ядро и расширение.

1. Базовый модуль (Ядро: предикаты и свойства)

Эти функции дешевы, не требуют сложной математики и нужны практически в любой задаче (от парсеров до физики).

Предикаты отношений (возвращают Boolean)

• IsEmpty(X) — проверка на пустой интервал (если допускается a > b или специальный флаг NaN).
• IsPoint(X) (или IsSingleton) — вырожденный интервал-точка (a = b).
• Contains(X, val) (или InVal) — входит ли конкретное число val в интервал: (a <= val) and (val <= b).
• IsSubset(X, Y) (In) — входит ли X целиком в Y: (c <= a) and (b <= d).
• IsInterior(X, Y) — строгое вхождение без касания границ: (c < a) and (b < d).
• Overlap(X, Y) — есть ли общая точка: (a <= d) and (c <= b).
• Adjacent(X, Y) (или Touches) — касаются ли интервалы ровно в одной граничной точке без перекрытия (b = c или d = a). Для целых чисел также полезен вариант Contiguous (b + 1 = c или d + 1 = a), когда два диапазона сливаются в один непрерывный.

Базовые характеристики (возвращают число)

• Width(X) (или Diam / Len) — ширина/длина: b - a (для целых часто b - a + 1, зависит от конвенции).
• Mid(X) — середина (номинальное значение): a + (b - a) * 0.5 (важно считать именно так, а не (a + b) / 2, чтобы избежать переполнения).
• Rad(X) — радиус (абсолютная погрешность \(\pm \Delta \)): (b - a) * 0.5.

2. Теоретико-множественные операции (возвращают новый интервал)

Эти функции удобно иметь либо в базовом модуле, либо в первом уровне расширения:
• Intersect(X, Y) (X ∩ Y) — общая часть двух интервалов: [\max(a, c), \min(b, d)]. Если интервалы не пересекаются, возвращает пустой интервал (или False через TryIntersect(X, Y, out Res)).
• Hull(X, Y) (X ⊔ Y, выпуклая оболочка) — наименьший интервал, содержащий оба исходных: [\min(a, c), \max(b, d)] (закрывает дыру между ними, если они не пересекаются).
• Union(X, Y) — объединение. Возвращает один интервал только если Overlap(X, Y) или Adjacent(X, Y) истинны (иначе объединение состоит из двух разорванных кусков).
• Subtract(X, Y) (разность X \ Y) — полезно для вырезания диапазонов. В общем случае может дать 0, 1 или 2 интервала (если Y вырезает середину X).

3. Модуль расчётов с погрешностями (Интервальная арифметика)

Сюда выносится всё, что превращает интервал в инструмент для надёжных вычислений:
• Конструкторы из погрешности:
	• FromMidRad(mid, rad) \(\rightarrow [mid - rad, mid + rad]\)
	• FromRelError(val, relPct) \(\rightarrow \) создание интервала по номиналу и относительной погрешности в процентах.
• Трансформации:
	• Inflate(X, eps) / Widen(X, eps) — расширение границ на величину eps ([a - eps, b + eps]), используется для запаса прочности или компенсации ошибок округления.
	• Clamp(X, Bounds) — обрезка интервала по допустимым границам (по сути, тот же Intersect).
• Метрики точности и расстояния:
	• RelError(X) — относительная погрешность: Rad(X) / Abs(Mid(X)).
	• Dist(X, Y) — расстояние между интервалами (0, если пересекаются; c - b или a - d, если разделены).
	• HausdorffDist(X, Y) (метрика Хаусдорфа) — максимальное расхождение границ: \max(|a - c|, |b - d|) (показывает, насколько близки два интервала по положению и размеру одновременно).
	• Mag(X) (magnitude) — максимальный модуль числа в интервале: \max(|a|, |b|).
	• Mig(X) (mignitude) — минимальный модуль числа в интервале (0, если 0 in X, иначе \min(|a|, |b|)). Критически важна перед делением на интервал, чтобы проверить близость к нулю.

Рекомендуемый минимальный набор (MVP)

Если не хочется раздувать код, но нужно закрыть 95% сценариев:
1. В базу (к Diff): Contains(val), Overlap, Adjacent, Width, Mid, Rad, TryIntersect, Hull.
2. В модуль погрешностей: FromMidRad, Inflate, RelError, Mag, Mig, арифметика + - * /.
