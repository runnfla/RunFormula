#### 1. Введение

Комплексные числа в RunFormula можно использовать в качестве 2D радиус-векторов, т.е. векторов на двумерной плоскости, начало которых совпадает с началом координат. При этом координата X конца вектора соответствует вещественной части комплексного числа, а координата Y — мнимой части.

Встроенные операции и функции, применимые к комплексным числам (арифметические операции, функции arg(), conj(), rect(), abs() и др.), сохраняют понятный геометрический смысл при интерпретации комплексного числа как радиус-вектора.

Данный подключаемый модуль расширяет возможности работы с векторной геометрией, добавляя специализированные функции, которые не имеют прямого аналога в стандартной комплексной арифметике.

#### 2. Оператор скалярного произведения векторов

В RunFormula имеется встроенный бинарный оператор "*." для вычисления скалярного произведения векторов. Например:
```
  [(2, 5)] *. [(7, 12)]      // результат 74
```
Оператор скалярного произведения векторов имеет тот же приоритет, что и оператор арифметического умножения. Оператор доступен без подключения данного модуля.

#### 3. Функции для работы с 2D радиус-векторами

`cross(<вектор 1>, <вектор 2>)` - возвращает вещественное число (скаляр) равное косому (псевдоскалярному) произведению векторов

`rotate(<вектор>, <угол>)` - поворачивает вектор на заданный угол (в радианах)

`norm(<вектор>)` - возвращает безразмерный вектор единичной длины, сонаправленный с аргументом

`angle(<вектор 1>, <вектор 2>)` - возвращает угол (в радианах) между векторами

`proj(<вектор 1>, <вектор 2>)` - возвращает вектор, являющийся векторной проекцией вектора 1 на вектор 2

`distsq(<точка 1>, <точка 2>)` — возвращает квадрат расстояния между двумя точками. Применяется для оптимизации сравнения расстояний без извлечения квадратного корня.

`perp(<вектор>)` - поворачивает вектор на pi/2 радиан (90 градусов против часовой стрелки). Поворот на -pi/2 радиан (90 градусов по часовой стрелке) можно выполнить как `perp(-<вектор>)` или `-perp(<вектор>)`. 

`lerp(<точка 1>, <точка 2>, <коэффициент>)` — возвращает точку на отрезке между точкой 1 и точкой 2. Положение точки задается вещественным коэффициентом: 0 соответствует точке 1, 1 - точке 2. При значениях коэффициента вне диапазона 0..1 выполняет экстраполяцию за пределы отрезка.

`cmpvect(<вектор 1>, <вектор 2>)` - сравнивает длины векторов, возвращает -1 - если длина вектора 1 меньше вектора 2, 0 - если длины векторов равны, 1 - если длина вектора 1 больше вектора 2

#### 4. Дополнительные функции

Функции векторной арифметики могут быть реализованы непосредственно в скрипте RunFormula. Например:
```
// Отражение вектора V относительно прямой, проходящей через начало координат с нормалью N.
func Reflect(V, N);
  V - proj(V, N)*2
endfunc;

// Центральная симметрия (отражение) точки V относительно центра C
func CenterMirror(V, C);
  C*2 - V
endfunc;

// Середина отрезка между точками V и C
func MidPoint(V, C);
  (V + C)/2
endfunc;
```
