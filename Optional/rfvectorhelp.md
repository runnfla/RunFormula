### 12. Встроенные функции

`cross(<вектор1>, <вектор2>)` - возвращает вещественное число (скаляр) равное косому (псевдоскалярному) произведению векторов

`rotate(<вектор>, <угол>)` - поворачивает вектор на заданный угол

`normalize(<вектор>)` - возвращает безразмерный вектор единичной длины, сонаправленный с аргументом

`angle(<вектор1>, <вектор2>)` - возвращает угол между векторами

`project(<вектор1>, <вектор2>)` - возвращает вектор, являющийся векторной проекцией вектора1 на вектор2

`distsq(<точка1>, <точка2>)` — возвращает квадрат расстояния между двумя точками. Может использоваться для определения расстояния без извлечения квадратного корня.

`perp(<вектор>)` - поворачивает вектор на pi/2 (90 градусов против часовой стрелки). Поворот на -pi/2 (90 градусов по часовой стрелке) можно выполнить как `perp(-<вектор>)` или `-perp(<вектор>)`.

`result([результат])` - прерывает выполнение скрипта. Может быть задан необязательный параметр - результат скрипта. Если параметр не задан, то результат скрипта равен None.

`exit([результат])` - досрочный выход из функции. Может быть задан необязательный параметр - результат функции. Если параметр не задан, то результат функции равен None. Если `exit([результат])` выполняется в глобальном блоке, то прерывает выполнение скрипта.

`break([результат])` - досрочный выход из цикла. Может быть задан необязательный параметр - результат цикла. Если параметр не задан, то результат цикла равен None.

`continue()` - досрочная итерация цикла

`if(<условие>, <параметр 1> [, параметр 2])` - если условие выполнено (не равно 0 (False)), то возвращает значение параметра 1. Если условие не выполнено (равно 0 (False)), то возвращает значение параметра 2, если он задан, либо None.

`repeat(<условие>, <параметр>)` - циклически вычисляет значения параметра, пока выполняется условие (условие не равно 0 (False)). Возвращает последнее значение параметра, либо None, если ни одной итерации цикла не было.

`type(<параметр>)` - возвращает целое число, соответствующее типу параметра:
<pre>
  0 - нет значения, None
  1 - целое число
  2 - вещественное число
  3 - зарезервировано
  4 - комплексное число
  5 - символ ASCII
  6 - текстовая строка
  7 - интервал
  8 - интервал с целыми границами
  9 - зарезервировано для массива
</pre>

#### 12.b. Математические функции

`sqrt(<аргумент>)` - возвращает квадратный корень аргумента. Аргумент может иметь размерность.

`cbrt(<аргумент>)` - возвращает кубический корень аргумента. Аргумент может иметь размерность.

`exp(<аргумент>)` - возвращает экспоненту аргумента

`pow(<основание>, <показатель степени>)` - возводит основание в заданную степень

`ln(<аргумент>)` - возвращает натуральный логарифм аргумента

`log(<аргумент>, <основание>)` - возвращает логарифм аргумента по заданному основанию

`sin(<аргумент>)` - возвращает синус аргумента

`cos(<аргумент>)` - возвращает косинус аргумента

`tan(<аргумент>)` - возвращает тангенс аргумента

`arctan(<аргумент>)` - возвращает арктангенс аргумента

`abs(<аргумент>)` - возвращает абсолютное значение аргумента. Для комплексного числа возвращает его модуль. Для интервала возвращает интервал абсолютных значений всех его чисел. Для символа ASCII возвращает его код.

#### 12.c. Функции для работы с комплексными числами

`re(<комплексное число>)` - возвращает действительную часть комплексного числа

`im(<комплексное число>)` - возвращает мнимую часть комплексного числа

`cplex(<действительная часть>, <мнимая часть>)` - возвращает комплексное число, сформированное по заданной действительной и мнимой части

`arg(<комплексное число>)` - возвращает безразмерный аргумент (фазу) комплексного числа. Модуль (абсолютное значение) комплексного числа можно получить с помощью функции abs().

`conj(<комплексное число>)` - возвращает комплексно-сопряженное число

`rect(<модуль>, <аргумент>)` - возвращает комплексное число, сформированное по заданному модулю (абсолютному значению) и аргументу (фазе). Аргумент должен быть безразмерным.

#### 12.d. Функции для работы с интервалами

`left(<интервал>)` - возвращает левую границу интервала

`right(<интервал>)` - возвращает правую границу интервала

`range(<левая граница>, <правая граница>)` - возвращает интервал, сформированный по заданной левой и правой границе. Левая граница должна быть меньше или равна правой.

`ball(<середина>, <полуширина>)` - возвращает интервал, сформированный по заданной середине и полуширине (отклонению от середины)

`margin(<интервал>)` - возвращает полуширину (отклонение от середины) интервала. Середину интервала можно получить с помощью функции re(), например:
```
    X = [10:20]; re(X) & "+-" & margin(X)    // результат 15+-5
```

#### 12.e. Функции округления

`frac(<аргумент>)` - возвращает дробную часть аргумента. Дробная часть всегда положительна и вычисляется как математическая дробная часть числа, т.е. как разность между числом и его округлением к меньшему. Для комплексных чисел дробная часть вычисляется отдельно для действительной и мнимой части. Для целых чисел и символов ASCII возвращает вещественный 0. Для интервалов функция не допустима. Например:
```
  X = frac(1.3)    // результат 0.3
  X = frac(-1.3)   // результат 0.7
```

`trunc(<аргумент>)` - возвращает целую часть аргумента. Для комплексных чисел и интервалов целая часть вычисляется отдельно для действительной и мнимой части и границ интервала. При возможности, преобразует тип результата к целому числу и интервалу с целыми границами.

`floor(<аргумент>)` - округляет аргумент до ближайшего меньшего целого числа. Для комплексных чисел и интервалов округление выполняется отдельно для действительной и мнимой части и границ интервала.

`ceil(<аргумент>)` - округляет аргумент до ближайшего большего целого числа. Для комплексных чисел и интервалов округление выполняется отдельно для действительной и мнимой части и границ интервала.

`round(<аргумент>)` - округляет аргумент. Производится математическое округление к ближайшему целому числу. Для интервала левая граница округляется вниз, правая вверх. Комплексные числа округляются в полярных координатах, фаза (аргумент) комплексного числа округляется в градусах.

#### 12.e. Функции для работы со строками и символами ASCII

`length(<строка>)` - возвращает длину строки в байтах

`string(<параметр>)` - преобразует параметр в строку (эквивалентно <параметр> & "")

`find(<строка>, <шаблон>, [смещение])` - ищет шаблон в строке и возвращает позицию его начала. Если задан необязательный положительный параметр [смещение], то поиск начинается с позиции, заданной этим параметром. Сравнение строки с шаблоном побайтовое (с учетом регистра символов). Смещение и результат отсчитываются начиная с 0 от начала строки. Если шаблон не найден, то возвращает -1. Если строка или шаблон пустые или смещение больше или равно длине строки, то возвращает -1.

--- > если шаблон пустой - то 0 или смещение

`substr(<строка>, <интервал>)` - возвращает участок строки, позиции начала и конца которого заданы интервалом. Интервал целочисленный. Позиции в строке отсчитываются начиная с 0. Если левая или правая границы интервала лежат вне строки, то они приводятся к началу или концу строки соответственно. Если интервал полностью лежит вне строки, то возвращает None. Если возвращаемое значение является единственным символом, то он возвращается как тип символа ASCII.

`val(<строка>)` - преобразует строку, заданную в едином числовом формате, в числовое значение

`char(<целое число>)` - преобразует младший байт целого числа в символ ASCII. Код символа ASCII можно получить с помощью функции abs().

`hexstr(<целое число>)` - преобразует целое число в его текстовое представление в шестнадцатеричном виде

#### 12.e. Функции сравнения

`compare(<аргумент 1>, <аргумент 2>)` - сравнивает аргументы, возвращает -1 0 +1

`sign(<параметр>)` - возвращает значения -1, 0, +1 в соответствии со знаком параметра.
<pre>
  - для None возвращает 0
  - для комплексного числа результат -1 или +1 определяется по действительной части. Если действительная часть равна 0, то по мнимой части. Если действительная и мнимая части равны 0, то возвращает 0.
  - для строки возвращает +1, если ее длина больше нуля, иначе возвращает 0
  - для символа ASCII возвращает 0, если его код равен 0 ("^@"), иначе возвращает +1
  - для интервала возвращает 0, если число 0 входит в интервал, иначе результат -1 или +1 определяется левой границей
</pre>

#### 12.f. Функции для работы с физическими размерностями

`match((<параметр 1>, <параметр 2>)` - сравнивает размерности параметров, возвращает -1 (True), если параметры имеют одинаковые размерности, иначе возвращает 0 (False)

`qty(<параметр>, <размерность>)` - присваивает безразмерному параметру размерность, заданную в виде строки. При необходимости производится преобразование параметра в соответствии с заданной размерностью, например:
```
  qty(20, "degC")        // результат 293.15 K
```

`conv(<параметр>, <размерность>)` - преобразует параметр, имеющий размерность, в безразмерное значение. При необходимости производится преобразование параметра в соответствии с заданной размерностью, например:
```
  conv(293.15 `K`, "degC")      // результат 20
```

`unitstr(<параметр>)` - возвращает размерность параметра в виде строки. Если параметр не имеет размерности, то возвращает None.
