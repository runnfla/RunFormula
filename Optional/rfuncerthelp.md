#### 1. Введение

Данный модуль добавляет в RunFormula поддержку расчетов с величинами, заданными с неопределенностью. В отличие от интервальной арифметики, реализованной в базовом наборе функций RunFormula, функции и операторы этого модуля обрабатывают интервалы методом переноса неопределенностей (на основе частных производных), если в их описании не указано иное.

Такой метод применяется при обработке экспериментальных данных, расчетов неопределенностей косвенных измерений и анализе допусков, когда отклонения носят случайный характер.

**Замечание:** Если функция или оператор принимает два и более аргумента, то предполагается, что соответствующие входные величины статистически независимы. Поэтому не следует использовать одну и ту же величину в выражении многократно: например, вместо `X *~ X` нужно применять функцию `unc.pow(X, 2)`.

Аргументами функций и операторов модуля могут быть интервалы, целые и вещественные числа (в том числе символы ASCII), если не указано иное. Результатом является интервал. Проверка на производится. 

#### 2. Арифметические операторы, учитывающие неопределенности

Реализованы следующие бинарные арифметические операторы, выполняющие расчеты с учетом неопределенностей величин:
<pre>
  +~       : сложение
  -~       : вычитание
  *~       : умножение
  /~       : деление
</pre>
Операторы, учитывающие неопределенности, имеют те же приоритеты, что и соответствующие стандартные арифметические операторы. Операторы доступны без подключения данного модуля.

#### 3. Математические функции, учитывающие неопределенности 

`unc.sqrt(<аргумент>)` - возвращает квадратный корень аргумента. Аргумент может иметь размерность.

`unc.cbrt(<аргумент>)` - возвращает кубический корень аргумента. Аргумент может иметь размерность.

`unc.exp(<аргумент>)` - возвращает экспоненту аргумента

`unc.pow(<основание>, <показатель степени>)` - возводит основание в заданную степень. Середина интервала основания должна быть больше нуля. Если показатель степени является целым числом, то основание может иметь размерность, а середина его интервала может быть меньше нуля.

`unc.ln(<аргумент>)` - возвращает натуральный логарифм аргумента

`unc.log(<аргумент>, <основание>)` - возвращает логарифм аргумента по заданному основанию

`unc.sin(<аргумент>)` - возвращает синус аргумента

`unc.cos(<аргумент>)` - возвращает косинус аргумента

`unc.tan(<аргумент>)` - возвращает тангенс аргумента

`unc.arctan(<аргумент>)` - возвращает арктангенс аргумента

`unc.hypot(<аргумент 1>, <аргумент 2>)` - возвращает корень из суммы квадратов аргументов

#### 4. Функции для расчета неопределенности

`unc.span(<величина 1>, <величина 2> [, ... величина N])` - вычисляет невзвешенное среднее значение независимых величин и его стандартную неопределенность (СКО), объединяя в квадратуре разброс значений между собой и их индивидуальные (независимые) неопределенности

`unc.accum(<накопленный интервал>, <добавляемая величина>, <порядковый номер>)` - инкрементально обновляет среднее значение и его стандартную неопределенность (СКО) при добавлении новой величины к накопленному интервалу для заданного порядкового номера добавляемой величины. Добавляемая величина задается числом. Порядковый номер - целое число, начиная с 1.

`unc.wmean(<интервал 1>, <интервал 2> [, ... интервал N])` - 
вычисляет взвешенное среднее значение независимых величин и его стандартную неопределенность (СКО) с учетом коэффициента Бирджа. Вес каждой величины определяется ее неопределенностью - аргументами функции должны быть интервалы с ненулевой полушириной (отклонением от середины).

`unc.add(<величина>, <неопределенность>)` - добавляет к величине независимую неопределенность, заданную числом, объединяя в квадратуре неопределенность величины и заданную неопределенность

#### 5. Дополнительные функции

`inflate(<интервал>, <коэффициент>)` - умножает полуширину (отклонение от середины) интервала на заданный безразмерный коэффициент. Середина интервала не изменяется.

`tcrit(<доверительная вероятность>, <число степеней свободы>)` - вычисляет двусторонний критический коэффициент Стьюдента для заданной доверительной вероятности и числа степеней свободы. Используется разложение Корниша — Фишера на основе рациональной аппроксимации Аклама квантиля нормального распределения.

#### 6. Примеры расчета доверительного интервала серии измерений

`Пример 1:` Произведено по 3 измерения напряжения вольтметром, имеющим точность +-1.5% от измеренной величины, и вольтметром, имеющим точность +- 1 V. Необходимо определить среднее значение напряжения и его доверительный интервал с вероятностью 0.95. Скрипт RunFormula:
```
// результаты измерений
X11 = 229 `V`;
X12 = 227 `V`;
X13 = 230 `V`;

X21 = 230 `V`;
X22 = 231 `V`;
X23 = 229 `V`;

// вычисление среднего значения и разброса для каждой серии
V1 = unc.span(X11, X12, X13);
V2 = unc.span(X21, X22, X23);

// добавление систематической приборной ошибки
mid1 = re(V1);
V1 = unc.add(V1, mid1 * 0.015 / sqrt(3));
V2 = unc.add(V2, 1 `V` / sqrt(3));

// вычисление общего среднего значения и разброса
V = unc.wmean(V1, V2);

// расширенная неопределенность, коэффициент охвата k = 2 соответствует доверительной вероятности ~0.95
U = inflate(V, 2);  // результат [228.306159470776:231.362541235513] V
```

`Пример 2:` Необходимо выполнить 100 опросов датчика с паузой 0.1 секунды и определить среднее значение и его доверительный интервал с вероятностью 0.95. Скрипт RunFormula:
```
X = none;
for(N = [1:100],
  do
    X = unc.accum(X, D, N);   // переменная D - опрос датчика
    
    T = tick() + 100;
    repeat((tick() - T) < 0, none);    // задержка 0.1 сек
    
  end, 0);

// расширенная неопределённость с вероятностью 0.95: коэффициент Стьюдента t(0.95, 99) ~ 1.984
Z = inflate(X, tcrit(0.95, 99));  // результат
```

#### 7. Оценка неопределённости измерений по методике GUM

Краткая справка по оценке неопределенности измерения по международной методике GUM (Guide to the Expression of Uncertainty in Measurement).

**Основные понятия**

`Среднеквадратичное (или стандартное) отклонение (СКО)` - это квадратный корень из суммы квадратов разностей между каждым значением в наборе данных и их общим средним, разделенной на количество значений минус 1:

&nbsp; s = sqrt( (1 / (N - 1)) * сумма((x_i - x_среднее) ** 2) )

`Неопределённость типа A` — статистическая: оценивается по разбросу повторных измерений. Для серии из N отсчетов стандартная неопределённость среднего вычисляется как:

&nbsp; u_A = s / sqrt(N),

Результат — это СКО среднего, а не отдельного измерения: при увеличении N оно уменьшается как 1/sqrt(N).

`Неопределённость типа B` — нестатистическая: паспортная погрешность прибора, допуски, влияние условий. Если известен предел погрешности theta (интервал +-theta) и других сведений о распределении нет, по GUM принимается равномерное распределение. Его СКО:

&nbsp; u_B = theta / sqrt(3)

*Откуда sqrt(3): у равномерного распределения на интервале [-theta, +theta] дисперсия равна theta ** 2 / 3, а стандартная неопределённость — это СКО, то есть sqrt(theta ** 2 / 3) = theta / sqrt(3).*

`Стандартная неопределенность` — одно число: СКО (или его эквивалент для типа B). Именно в такой форме вклады объединяются между собой.

`Расширенная неопределённость` — интервал +-U, который накрывает истинное значение с заданной вероятностью:

&nbsp; U = k * u_c,

где суммарная стандартная неопределённость:

&nbsp; u_c = sqrt(u_1 ** 2 + u_2 ** 2 + ... )

**Квадратурное сложение**

Независимые вклады неопределенностей складываются в квадратуре (по дисперсиям), а не арифметически: sqrt(u_1 ** 2 + u_2 ** 2). Причина в том, что дисперсии независимых величин складываются, а СКО — нет. Арифметическое сложение дает завышенный (но надёжный) интервал; современная конвенция — квадратура.

Ключевое правило однородности: складывать в квадратуре можно только стандартные неопределённости (СКО‑эквиваленты). Нельзя смешивать расширенную неопределённость одного слагаемого с пределом другого — перед сложением все вклады приводят к стандартной форме, а коэффициент охвата применяют один раз, в самом конце расчета.

**Откуда берётся k = 2**

Коэффициент охвата k = 2 — общепринятая конвенция GUM. Для нормального распределения точное значение для 95% — k_0.95 = 1.96; двойка — это округление вверх, накрытие примерно 95.45%. Когда суммарная неопределенность содержит равномерные вклады (например, приборные погрешности), реальное накрытие при k = 2 несколько выше 95% — интервал получается слегка консервативным.

Альтернатива для строгих случаев — коэффициент Стьюдента t(α, ν) с эффективным числом степеней свободы (по формуле Уэлча–Саттертуэйта). При ν ≳ 20 он практически совпадает с k = 2, поэтому для типовых лабораторных измерений конвенции k = 2 обычно достаточно. См. функцию tcrit() в Примере 2: там чистый тип A с N = 100, и вместо двойки использован точный коэффициент Стьюдента.

**Функции модуля**

| Шаг методики | Функция | Что делает |
| --- | --- | --- |
| Среднее и u_A по серии | unc.span(x1, x2, …) | центр — среднее, полуширина — s / sqrt(N) |
| Наращивание серии по одному отсчёту | unc.accum(X, x, N) | обновляет среднее и u_A при поступлении нового отсчёта |
| Добавление вклада типа B | unc.add(X, u_B) | u_c = sqrt(u_X^2 + u_B^2), центр не меняется; вклад задаётся числом |
| Объединение серий разных приборов | unc.wmean(X1, X2) | взвешенное среднее с весами 1 / u^2, контроль согласованности (Бирж) |
| Расширенная неопределённость | inflate(X, k) | U = k * u_c; применяется последней |
| Коэффициент Стьюдента | tcrit(α, ν) | для строгого интервала при чистом типе A |

**Типовые схемы**
```
// Один прибор, серия из N отсчётов:

R = unc.span(x1, x2, x3);          // u_A — только случайный разброс
R = unc.add(R, theta/sqrt(3));     // + u_B (прибор), один раз
U = inflate(R, 2);                 // интервал ~95%


// Много отсчётов с накоплением:

X = unc.accum(X, D, N);            // в цикле по отсчётам
Z = inflate(X, tcrit(0.95, N-1));  // чистый тип A — Стьюдент


// Два прибора:

R1 = unc.add(unc.span(x11, x12, x13), th1/sqrt(3));
R2 = unc.add(unc.span(x21, x22, x23), th2/sqrt(3));
V  = unc.wmean(R1, R2);            // веса по неопределённостям
U  = inflate(V, 2);
```

При нескольких приборах каждая серия получает `свою` приборную систематику. Общая для всех приборов систематика (например, погрешность эталона, по которому откалиброваны оба прибора) — коррелированный вклад: усреднение её не уменьшает, поэтому она добавляется `один раз в конце`, после `unc.wmean()`.

**Типичные ошибки**

`- Передать в unc.add() интервал вместо числа.` Центр интервала будет трактован как вклад в СКО: неопределённость раздуется на порядки, вес точного прибора в `unc.wmean()` обнулится, и результат выродится в данные менее точного прибора.
`- Передать в `unc.span() отсчёты, уже обременённые приборной погрешностью одного прибора.` Систематика прибора — общий (коррелированный) вклад для всех его отсчётов: усреднение её не гасит. Но внутри `unc.span()` такие вклады обрабатываются как независимые случайные ошибки и подавляются как `1/sqrt(N). В предельном случае (все отсчёты равны) неопределённость вообще станет нулевой. Приборную погрешность следует добавлять через `unc.add()` после `unc.span()`, один раз.
`- Применить `inflate()` к промежуточному результату, а потом ещё раз добавить вклад.` Коэффициент охвата накопится дважды, интервал станет неверным.
`- Смешать уровни доверия - прибавить к расширенной неопределённости (`k = 2`, ~95%) новую стандартную неопределённость.` Результат не интерпретируется ни как 95%-интервал, ни как стандартная неопределённость.
`- Умножить приборный предел на 1/sqrt(3) дважды` — "уже в СКО" и "ещё раз для надёжности".

Общее правило для серий:

> Вклады, общие для всей серии (один прибор, один эталон, одни условия),
> добавляются один раз — к результату серии, а не к отдельным отсчётам.
> Пересчёт предела в СКО через `θ/√3` выполняется тоже один раз, в момент
> добавления.
