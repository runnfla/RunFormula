#### 1. Введение

Данный модуль добавляет в RunFormula поддержку расчетов с величинами, заданными с неопределенностью. В отличие от интервальной арифметики, реализованной в базовом наборе функций RunFormula, функции и операторы этого модуля обрабатывают интервалы методом переноса неопределенностей (на основе частных производных), если в их описании не указано иное.

Такой метод применяется при обработке экспериментальных данных, расчетов неопределенностей косвенных измерений и анализе допусков, когда отклонения носят случайный характер.

**Замечание:** Если функция или оператор принимает два и более аргумента, то предполагается, что соответствующие входные величины статистически независимы. Поэтому не следует использовать одну и ту же величину в выражении многократно: например, вместо `X *~ X` нужно применять функцию `unc.pow(X, 2)`.

Аргументами функций и операторов модуля могут быть интервалы, целые и вещественные числа (в том числе символы ASCII), если не указано иное. Результатом является интервал.

**Замечание:** При больших относительных неопределенностях аргументов перенос неопределенностей теряет точность, поэтому результат может содержать значения вне области определения функции. 

#### 2. Арифметические операторы, учитывающие неопределенности

Реализованы следующие бинарные арифметические операторы, выполняющие расчеты с учетом неопределенностей величин:
<pre>
  +~       : сложение
  -~       : вычитание
  *~       : умножение
  /~       : деление
</pre>
Операторы, учитывающие неопределенности, имеют те же приоритеты, что и соответствующие стандартные арифметические операторы. Операторы доступны без подключения данного модуля.

#### 3. Математические функции, учитывающие неопределенности 

`unc.sqrt(<аргумент>)` - возвращает квадратный корень аргумента. Аргумент может иметь размерность.

`unc.cbrt(<аргумент>)` - возвращает кубический корень аргумента. Аргумент может иметь размерность.

`unc.exp(<аргумент>)` - возвращает экспоненту аргумента

`unc.pow(<основание>, <показатель степени>)` - возводит основание в заданную степень. Середина интервала основания должна быть больше нуля. Если показатель степени является целым числом, то основание может иметь размерность, а середина его интервала может быть произвольной.

`unc.ln(<аргумент>)` - возвращает натуральный логарифм аргумента

`unc.log(<аргумент>, <основание>)` - возвращает логарифм аргумента по заданному основанию

`unc.sin(<аргумент>)` - возвращает синус аргумента

`unc.cos(<аргумент>)` - возвращает косинус аргумента

`unc.tan(<аргумент>)` - возвращает тангенс аргумента

`unc.arctan(<аргумент>)` - возвращает арктангенс аргумента

`unc.hypot(<аргумент 1>, <аргумент 2>)` - возвращает корень из суммы квадратов аргументов

#### 4. Функции для расчета неопределенности

`unc.span(<величина 1>, <величина 2> [, ... величина N])` - вычисляет невзвешенное среднее значение независимых величин и его стандартную неопределенность (СКО), объединяя в квадратуре разброс значений между собой и их индивидуальные независимые неопределенности

`unc.accum(<накопленный интервал>, <добавляемая величина>, <порядковый номер>)` - инкрементально обновляет среднее значение и его стандартную неопределенность (СКО) при добавлении новой величины к накопленному интервалу для заданного порядкового номера добавляемой величины. Добавляемая величина задается числом. Порядковый номер - целое число, начиная с 1.

`unc.wmean(<интервал 1>, <интервал 2> [, ... интервал N])` - 
вычисляет взвешенное среднее значение независимых величин и его стандартную неопределенность (СКО) с учетом коэффициента Бирджа. Вес каждой величины определяется ее неопределенностью - аргументами функции должны быть интервалы с ненулевой полушириной (отклонением от середины).

`unc.add(<величина>, <неопределенность>)` - добавляет к величине независимую неопределенность, заданную числом, объединяя в квадратуре неопределенность величины и заданную неопределенность

#### 5. Дополнительные функции

`inflate(<интервал>, <коэффициент>)` - умножает полуширину (отклонение от середины) интервала на заданный безразмерный коэффициент. Середина интервала не изменяется.

`tcrit(<доверительная вероятность>, <число степеней свободы>)` - вычисляет двусторонний критический коэффициент Стьюдента для заданной доверительной вероятности и числа степеней свободы. Для вычисления используется разложение Корниша — Фишера на основе рациональной аппроксимации Аклама квантиля нормального распределения.

#### 6. Примеры расчета доверительного интервала серии измерений

`Пример 1:` Произведено по 3 измерения напряжения вольтметром, имеющим точность +-1.5% от измеренной величины, и вольтметром, имеющим точность +-1 V. Необходимо определить среднее значение напряжения и его доверительный интервал с вероятностью 0.95. Скрипт RunFormula:
```
// результаты измерений
X11 = 229 `V`;
X12 = 227 `V`;
X13 = 230 `V`;

X21 = 230 `V`;
X22 = 231 `V`;
X23 = 229 `V`;

// вычисление среднего значения и разброса для каждой серии
V1 = unc.span(X11, X12, X13);
V2 = unc.span(X21, X22, X23);

// добавление систематической приборной ошибки
V1 = unc.add(V1, re(V1) * 0.015 / sqrt(3));
V2 = unc.add(V2, 1 `V` / sqrt(3));

// вычисление общего среднего значения и разброса
V = unc.wmean(V1, V2);

// расширенная неопределенность, коэффициент охвата k = 2 соответствует доверительной вероятности ~0.95
U = inflate(V, 2);  // результат [228.306159470776:231.362541235513] V

// вывод результата
U = conv(signif(U), "V"));
"[ " & re(U) & " +- " & signif(margin(U)) & " ] V"
```

`Пример 2:` Необходимо выполнить 100 опросов датчика с паузой 0.2 секунды и определить среднее значение и его доверительный интервал с вероятностью 0.95. Скрипт RunFormula:
```
X = none;
for(N = [1:100],
  do
    X = unc.accum(X, D, N);   // переменная D - опрос датчика
    
    T = tick() + 200;
    repeat((tick() - T) < 0, none);    // задержка 0.2 сек
    
  end, 0);

// расширенная неопределенность с вероятностью 0.95: коэффициент Стьюдента t(0.95, 99) = ~1.984
Z = inflate(X, tcrit(0.95, 100 - 1));  // результат

// вывод результата
Z = signif(Z);
S = unitstr(re(A), true);
Z = conv(Z, S);
"[ " & re(Z) & " +- " & signif(margin(Z)) & " ] " & S;
```

#### 7. Оценка неопределенности измерений по методике GUM

Краткая справка по оценке неопределенности измерений по международной методике GUM (Guide to the Expression of Uncertainty in Measurement).

**Основные понятия**

`Среднеквадратичное отклонение (СКО)` - это квадратный корень из суммы квадратов разностей между каждым значением в наборе данных и их общим средним, разделенной на количество значений минус 1:

&nbsp; s = sqrt( сумма((x[i] - x_среднее) ** 2) / (N - 1))

`Неопределенность типа A` — статистическая: оценивается по разбросу повторных измерений. Для серии из N измерений стандартная неопределенность среднего вычисляется как:

&nbsp; u_A = s / sqrt(N)

Результат — это СКО среднего, а не отдельного измерения: при увеличении N оно уменьшается как 1/sqrt(N).

`Неопределенность типа B` — нестатистическая: паспортная погрешность прибора, допуски, влияние условий. Если известен предел погрешности theta (интервал +-theta) и других сведений о распределении нет, то по GUM принимается равномерное распределение. Его СКО:

&nbsp; u_B = theta / sqrt(3)

*Откуда sqrt(3): у равномерного распределения на интервале +-theta дисперсия равна theta ** 2 / 3, а стандартная неопределенность — это СКО, то есть sqrt(theta ** 2 / 3) = theta / sqrt(3).*

`Стандартная неопределенность` — одно число: СКО или его эквивалент для типа B. Именно в такой форме вклады объединяются между собой.

`Расширенная неопределенность` — интервал +-U, который накрывает истинное значение с заданной вероятностью:

&nbsp; U = k * u_c,

где суммарная стандартная неопределенность:

&nbsp; u_c = sqrt(u_1 ** 2 + u_2 ** 2 + ... )

**Квадратурное сложение**

Независимые вклады неопределенностей складываются в квадратуре (по дисперсиям), а не арифметически: sqrt(u_1 ** 2 + u_2 ** 2). Причина в том, что дисперсии независимых величин складываются, а СКО — нет. Арифметическое сложение дает завышенный (но надежный) интервал; современная конвенция — квадратура.

Ключевое правило однородности: складывать в квадратуре можно только стандартные неопределенности (СКО-эквиваленты). Нельзя смешивать расширенную неопределенность одного слагаемого с пределом другого — перед сложением все вклады приводят к стандартной форме, а коэффициент охвата применяют один раз, в самом конце расчета.

**Откуда берется k = 2**

Коэффициент охвата k = 2 — общепринятая конвенция GUM. Для нормального распределения точное значение для 95% — k_0.95 = 1.96; двойка — это округление вверх, накрытие примерно 95.45%. Когда суммарная неопределенность содержит равномерные вклады (например, приборные погрешности), реальное накрытие при k = 2 несколько выше 95% — интервал получается слегка консервативным.

Альтернатива для строгих случаев — коэффициент Стьюдента t(alpha, df) с эффективным числом степеней свободы (по формуле Уэлча–Саттертуэйта). При df > ~20 он практически совпадает с k = 2, поэтому для типовых лабораторных измерений конвенции k = 2 обычно достаточно. См. функцию `tcrit()` в Примере 2 - там чистый тип A с N = 100, и вместо двойки использован точный коэффициент Стьюдента.

**Функции модуля**

| Шаг методики | Функция | Что делает |
| --- | --- | --- |
| Среднее и u_A по серии | unc.span(x1, x2, ...) | центр - среднее, полуширина - s / sqrt(N) |
| Наращивание серии по одному отсчету | unc.accum(R, X, N) | обновляет среднее и u_A при поступлении нового отсчета |
| Добавление вклада типа B | unc.add(X, u_B) | u_c = sqrt(u_X ** 2 + u_B ** 2), центр не меняется; вклад задается числом |
| Объединение серий разных приборов | unc.wmean(X1, X2) | взвешенное среднее с весами 1 / u ** 2, контроль согласованности (коэфф. Бирджа) |
| Расширенная неопределенность | inflate(X, k) | U = k * u_c; применяется последней |
| Коэффициент Стьюдента | tcrit(alpha, df) | для строгого интервала при чистом типе A |

**Типовые схемы**
```
// Один прибор, серия из N отсчетов:

R = unc.span(x1, x2, x3);          // u_A — только случайный разброс
R = unc.add(R, theta/sqrt(3));     // + u_B (прибор), один раз
Z = inflate(R, 2);                 // интервал ~95%


// Много отсчетов с накоплением:

X = unc.accum(X, D, N);              // в цикле по отсчетам
Z = inflate(X, tcrit(0.95, N - 1));  // чистый тип A, коэфф. Стьюдента


// Два прибора:

X1 = unc.span(x11, x12, x13); 
R1 = unc.add(X1, theta1 / sqrt(3));
X2 = unc.span(x21, x22, x23);
R2 = unc.add(X2, theta2 / sqrt(3));
W  = unc.wmean(R1, R2);              // веса по неопределенностям
Z  = inflate(W, 2);
```

При нескольких приборах каждая серия получает "свою" приборную систематику. Общая для всех приборов систематика (например, погрешность эталона, по которому откалиброваны оба прибора) — коррелированный вклад: усреднение ее не уменьшает, поэтому она добавляется один раз в конце, после `unc.wmean()`.

**Типичные ошибки**

`- Передать в unc.add() интервал вместо числа.` Центр интервала будет трактован как вклад в СКО: неопределенность раздуется на порядки, вес точного прибора в `unc.wmean()` обнулится, и результат выродится в данные менее точного прибора.\
`- Передать в unc.span() отсчеты, уже обремененные приборной погрешностью одного прибора.` Систематика прибора — общий (коррелированный) вклад для всех его отсчетов: усреднение ее не гасит. Но внутри `unc.span()` такие вклады обрабатываются как независимые случайные ошибки и подавляются как `1/sqrt(N)`. В предельном случае (все отсчеты равны) неопределенность вообще станет нулевой. Приборную погрешность следует добавлять через `unc.add()` после `unc.span()` один раз.\
`- Применить inflate() к промежуточному результату, а потом еще раз добавить вклад.` Коэффициент охвата накопится дважды, интервал станет неверным.\
`- Смешать уровни доверия - прибавить к расширенной неопределенности (k = 2, ~95%) новую стандартную неопределенность.` Результат не интерпретируется ни как 95%-интервал, ни как стандартная неопределенность.\
`- Умножить приборный предел на 1/sqrt(3) дважды` — "уже в СКО" и "еще раз для надежности".\
