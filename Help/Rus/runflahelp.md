### 1. Краткое описание

Модуль RunFormula предназначен для вычисления математических выражений и физических формул, представленных в текстовом виде, с поддержкой скриптового языка и обработкой физических размерностей.

Поддерживаемые типы данных:
  - целые числа в десятичном, шестнадцатеричном и двоичном форматах;
  - числа с плавающей запятой в десятичной и научной нотации;
  - комплексные числа и операции над ними;
  - интервалы и операции над ними;
  - строки и символы ASCII;

Арифметические и логические операции: + - * / or and xor not shl (<<) shr (>>) mod (%) div == <> < <= >= > & (объединение строк) ** (возведение в целую степень).\
Поддерживаются переменные и их динамическая инициализация во время выполнения через внешнюю функцию обратного вызова.\
Есть базовый набор встроенных функций и возможность регистрации и использования дополнительных пользовательских функций.\
Функции управления потоком выполнения: if() repeat() exit() result() continue() break()\
Возможность объявления и последующего использования функций непосредственно в тексте формулы (подпрограммы).\
Поддержка физических размерностей, их контроль во время выполнения операций, автоматический расчет размерности результата и автоматическая конвертация значений из одной системы единиц в другую.\
Поддерживается директива define.\
Компиляция исходной формулы в байт-код для многократного выполнения.\
Минимум зависимостей (только SysUtils в базовой конфигурации).

#### 1.a. Интеграция RunFormula в проект

  - Скопируйте все файлы из каталога RunFormula (```runformula.pas``` и все файлы ```.inc```) в проект или в отдельный каталог;
  - Добавьте ```RunFormula``` в раздел ```uses``` секции `interface` или `implementation`, например, так:
```
  implementation
    uses RunFormula;
```
или, если используется отдельный каталог:
```
  implementation
    uses RunFormula in 'RunFormula/runformula.pas';
```
либо укажите путь к каталогу `RunFormula` в соответствующем параметре компилятора.

Самый простой способ использования RunFormula — вызвать функцию RunFlaParse и передать ее результат в функциии RunFlaExecStr или RunFlaExecVrt. Например:
```
  ShowMessage( RunFlaExecStr( RunFlaParse('9 * 3') ) ); // отображает 27
```
Функция RunFlaParse компилирует исходную формулу в байт-код для выполнения функциями RunFlaExecStr или RunFlaExecVrt. Результатом функции RunFlaExecStr является строка, а RunFlaExecVrt — переменная типа Variant.\
См. соответствующие разделы справки для получения дополнительной информации.

### 2. Синтаксис скриптового языка RunFormula

#### 2.a. Формат языка. Комментарии.

В скриптовом языке используется свободный формат записи. Пробелы, табуляция, переносы строк являются разделителями там, где это необходимо, а в остальных случаях игнорируются. Не допускаются пробелы внутри идентификаторов, чисел, конструкциях "функция(", "массив[", "единица измерения^показатель степени". Регистр символов не учитывается, за исключением оговоренных случаев.\
Комментарии могут быть записаны в фигурных скобках или после двойной наклонной черты. Например:
```
  { текст комментария }
  // текст комментария
```

#### 2.b. Целые числа

Целое число может быть задано в десятичной, шестнадцатеричной и двоичной форме. Например:
```
  X = 12345;       // целое в десятичной форме
  X = 0xA12B;      // целое в шестнадцатеричной форме
  X = 0a12bH;      // целое в шестнадцатеричной форме
  X = 10101b;      // целое в двоичной форме
```
Регистр символов не учитывается, за исключением префикса 0x.\
Допустимые диапазоны целых чисел:

&nbsp;&nbsp; -9223372036854775807 : 9223372036854775807 - в 64-разрядных системах;\
&nbsp;&nbsp; -2147483647 : 2147483647 - в 32-разрядных системах;\
&nbsp;&nbsp; -32767 : 32767 - в 16-разрядных системах;

Минимальное системное отрицательное число (-9223372036854775808 в 64-разрядных, -2147483648 в 32-разрядных, -32768 в 16-разрядных системах) может использоваться, однако в арифметических операциях оно считается вне допустимого диапазона и преобразуется в вещественное число. Если заданное десятичное число находится вне допустимого диапазона, то оно преобразуются в вещественное, однако для шестнадцатеричных и двоичных чисел такая проверка не производится.\
Конструкция "- число" интерпретируется как положительное число и унарный минус (с соответствующим приоритетом операции). Если необходимо задать именно отрицательное число, то следует использовать Единый числовой формат (квадратные скобки). Например:
```
  X = - 3 ** 2;       // результат -9
  X = -10 ** 2;       // результат -100
  X = [- 3] ** 2;     // результат 9
  X = [-10] ** 2;     // результат 100
```

#### 2.с. Вещественные числа

Вещественное число может быть задано в виде десятичного числа с точкой или в виде числа с порядком. Например:
```
  X = 12.34;
  Y = 0.12;
  X = 1E1;
  Y = 0.2e-4;
  Z = 23E+34;
```
Как и для целых чисел, конструкция "- число" интерпретируется как положительное число и унарный минус (с соответствующим приоритетом операции). Если необходимо задать именно отрицательное число, то следует использовать Единый числовой формат (квадратные скобки). Например:
```
  X = - 3.5 ** 2;          // результат -12.25
  X = -10.2E20 ** 2;       // результат -1.0404E42
  X = [- 3.5] ** 2;        // результат 12.25
  X = [-10.2E20] ** 2;     // результат 1.0404E42
```

#### 2.d. Текстовые строки

Текстовая строка может быть задана в кавычках или апострофах. Если строка задана в кавычках, то в ней могут быть апострофы и наоборот. Например:
```
  X = '"A"' & "'s'";       // результат "A"'s'
```
Пустая строка может быть задана как "", '' или константой None.\
Также для задание строки может использоваться символ ASCII с кодом 0x7.

#### 2.e. Символы ASCII

Символ ASCII может быть задан в виде строки, содержащей этот символ. В отличие от строки, символ ASCII интерпретируется в арифметических операциях как однобайтовое целое число, соответствующее его коду. Также с помощью префикса "^" может быть задан управляющий символ. Например:
```
  X = "B" - "A";       // результат 1
  X = "B" & "A";       // результат BA
  X = "One" & "^M" & "^J" & "Two";   // вывод One и Two в 2 строки
```

#### 2.f. Константы

Имеются предопределенные константы:
<pre>
  True       // -1 целое
  False      // 0 целое
  None       // пустая строка, значение не задано
  Pi         // 3.14159265358979323846
  E          // 2.71828182845904523536
  J          // мнимая 1
  MinInt     // минимальное системное целое число
  MaxInt     // максимальное системное целое число
</pre>

#### 2.g. Комплексные числа

Для задания комплексного числа можно использовать выражение с константой j - мнимая 1, встроенную функцию cplex(R, I) и Единый числовой формат (квадратные скобки). Например:
```
  X = [(-12.1, - 23.3)];      // результат (-12.1, -23.3)
  X = 4+5*j;                  // результат (4, 5)
  X = cplex(2, 3);            // результат (2, 3)
```

#### 2.h. Интервалы

Интервал может быть задан с помощью Единого числового формата (квадратных скобок) или встроенных функций range(L, R) и ball(C, M). Например:
```
  X = [-1.1:23];              // результат [-1.1:23]
  X = ["A":"Z"];              // результат [65:90]
  X = range(19, 23.5);        // результат [19:23.5]
  X = ball(10, 2);            // результат [8:12]
```
Левая граница интервала должна быть меньше или равна правой.

#### 2.i. Операторные скобки

Одно или несколько выражений может быть заключено в круглые скобки. Выражения в скобках вычисляются последовательно слева направо. Результат вычисления "скобок" - это результат последнего выражения. Выражения в скобках разделяются запятой или точкой с запятой. Не допускается цифра следующим символом после запятой или точки с запятой, следует вставить хотя бы один пробел. Например:
```
  5 * (4 - 7);                     // результат -15
  5 * (21, 21 + 1; 21 + 2);        // результат 115
  5 * (21 + 1; 21 + 2; 100);       // результат 500
```
Скобки c выражениями могут быть вложены друг в друга. Допускается ставить запятую или точку с запятой перед после последнего выражения в скобках.\
Вместо круглых скобок с той же целью можно использовать ключевые слова "do" и "end". Например:
```
  do
    X = 10;
    Y = 20;
    X + Y
  end
```
Если группа выражений открывалась круглой скобкой, то она должна быть и закрыта круглой скобкой, и, наоборот, если группа открывалась словом "do", то она должна быть закрыта словом "end".

#### 2.j. Математические операции

В таблице перечислены поддерживаемые математические операции для разных типов значений.
<pre>
                               Целое  Вещественное  Комплексное  Интервал  Символ ASCII  Строка

== <> < > <= >=                  +         +             +          +       как целое      +
+ - *                            +         +             +          +       как целое      -
/                          вещест. рез-т   +             +          +     вещест. рез-т    -
or and xor div mod (%)
shl (<<) shr (>>) not            +         -             -          -       как целое      -
- унарный                        +         +             +          +       как целое      -
**                               +         +             +          +       как целое      -
&                              строка    строка        строка     строка        +          +
</pre>
** - операция возведения в целую степень (положительную или отрицательную)\
& - операция объединения строк\
При переполнении целых чисел в операциях + - * ** - (унарный) результат конвертируется в вещественный тип. Для интервалов операции == и <> функционируют как in и not in, операции < > <= >= сравнивают интервалы по средним точкам.

#### 2.k. Приоритет операций

В выражении математические операции выполняются в соответствии со следующим приоритетом:
<pre>
  максимальный:  **                  // возведение в целую степень
                 - not               // унарные
                 * / shl (<<) shr (>>) div mod (%)
                 + -
                 &                   // объединение строк
                 == <> < > <= >=
                 and
                 or xor
  минимальный:   =                   // присваивание
</pre>
Операции присваивания (=) и возведения в степень (**) являются правоассоциативными и выполняются последовательно справа налево.

#### 2.l. Преобразование типов

Тип значения может быть автоматически преобразован в соответствии со следующей таблицей. В ней также указан тип Variant, используемый для передачи значений во внешние функции.
<pre>
                    Целое  Вещественное  Комплексное  Интервал  Символ ASCII  Строка  Variant

Целое         -->     +         +           X+0*j      [X:X]         -          +        +
Вещественное  -->     -         +           X+0*j      [X:X]         -          +        +
Комплексное   -->     -         -             +          -           -        (R, I)     R
Интервал      -->     -      (L+R)/2     (L+R)/2+0*j     +           -        [L:R]   (L+R)/2
Символ ASCII  -->     +         +           X+0*j      [X:X]         +          +       byte
Строка        -->     -         -             -          -           -          +        +
Variant       -->     +         +             -          -      if string[1]    +
</pre>

#### 2.m. Переменные и операция присваивания

В выражениях могут использоваться переменные. В имени переменной допускаются буквы латинского алфавита, цифры, точки (за исключением первого символа), подчеркивание.\
Значение переменной задается с помощью операции присваивания:

&nbsp;&nbsp; <переменная> = <выражение>

Перед использованием в выражении переменная должна быть определена с помощью оператора присваивания. Результат операции присваивания равен присваиваемому значению. Например:
```
  X=2+4;                     // результат 6
  abc=18/3;                  // результат 6
  ( X=4, Y=6.1;  Z=X+Y )     // результат 10.1
```
Поскольку операция присваивания правоассоциативная, в одном выражении допускается присвоение значения сразу нескольким переменным. Например:
```
  X = Y = Z = 3, X * Y * Z   // результат 27
```

### 3. Использование физических размерностей

#### 3.а. Единицы измерения

Числовому значению может быть присвоена физическая размерность, которая выражается через степени базовых единиц измерения. Диапазон показателя степени базовых единиц измерения в размерности - от -127 до 127. В 64-разрядных системах в размерности допускается до 8 базовых единиц, в 32-разрядных - до 4-х, в 16-разрядных - до 2. Может быть неограниченное количество производных единиц измерения.

#### 3.b. Синтаксис размерностей

Размерность задается в виде строки, состоящей из единиц измерения и показателей их степеней. Показатель степени указывается непосредственно за единицей измерения в формате "^число", без пробелов. Единицы измерения должны быть отделены друг от друга. Показатель степени "^1" может не указываться. Единицы измерений, имеющие отрицательные показатели степени, указываются в размерности после символа "/" с положительным показателем (в знаменателе). В размерности допускается только один символ "/". Если показатели степени всех единиц измерения отрицательные, то они указываются после конструкции "1/". В числителе и знаменателе размерности допускаются круглые скобки, которые игнорируются. Например:
```
  [10 m]; [10 m^3 kg]; [10 m/s]; [10 m / s^2]; [10 1/m^2]; [10 1/(m^2 kg)]
```
У единиц измерения могут быть указаны приставки (без пробела). Например:
```
  [10 m] + [100 cm]                  // результат 11 m 
  [10 m^2] + [1000 mm^2]             // результат 10.001 m^2 
  [10 cm/us^2] + [100 m/ms^2]        // результат 100.1 Gm/s^2 
``` 
Для единиц измерения и приставок учитывается регистр символов.

#### 3.c. Присвоение размерностей

Размерность может быть присвоена целому, вещественному, комплексному числу, интервалу, символу ASCII. Размерность в скрипте можно присвоить непосредственно заданному числовому значению, значению переменной в выражении (но не самой переменной), выражению, группе выражений в скобках, результату функции. Для присвоения размерность записывается в обратных апострофах после значения. Например:
```
  X = 10 `m/s` + 20`mm/us`                  // результат 20.01 km/s 
  X = 10; X`m` + X`mm`                      // результат 10.01 m 
  X = 10; range(X, X+1)`mm`+1`mm`           // результат [0.011:0.012] m
  X = 10; (X *2)`mm` + (X+2)`cm`            // 140 mm 
```
При присвоении размерности производится преобразование значения в соответствии с параметрами единиц изменения, порядком степени, приставками. Например:
```
  10 `km/h^2`   // результат 771.604938271605 um/s^2
```
Повторное присваивание размерности не допускается.

### 4. Единый числовой формат

Единый числовой формат используется во всех случаях при преобразовании числового значения в текстовую строку (за исключением символов ASCII) и при преобразовании текстовой строки в числовое значение. Единый числовой формат может использоваться в тексте скрипта для задания числовых значений. В этом случае текстовая строка, содержащая значение, указывается в квадратных скобках.

#### 4.a. Целые и вещественные числа

Формат целых и вещественных чисел соответствует формату целых и вещественных чисел, используемых в скрипте. Целое число может быть указано в десятичной, шестнадцатеричной и двоичной формах. Вещественной число может быть указано в форме с десятичной точкой и научном формате. 
Для отрицательного числа перед ним ставится минус. Как и в скрипте, для целых десятичных чисел производится проверка диапазона с автоматическим преобразованием в вещественный тип. Например:
```
  X = [-0x10] + [ - 20.3 ]            // целые и вещественные числа
```

#### 4.b. Символы ASCII

В качестве значения может быть указан символ ASCII в формате, используемом в скрипте. Минус перед символом ASCII не допускается. Например:
```
  X = ["M"] + ['^C']                  // символы ASCII
```

#### 4.c. Комплексные числа

Формат комплексного числа:
<pre>
  (действительная часть, мнимая часть)
</pre>
В качестве действительной и мнимой части могут указываться целые и вещественные числа, при необходимости, со знаком минус, и символы ASCII. Не допускается цифра следующим символом после запятой или точки с запятой, следует вставить хотя бы один пробел. Например:
```
  X = [( - 12.1, -12.45)]            // комплексное число 
```

#### 4.d. Интервалы

Формат интервала:
<pre>
  [левая граница:правая граница]
</pre>
В качестве левой и правой границ могут указываться целые и вещественные числа, при необходимости, со знаком минус, и символы ASCII. Левая граница интервала должна быть меньше или равна правой. Квадратные скобки могут быть опущены, а при задании интервала в тексте скрипта - должны быть опущены. Например:

```
  X = [ - 100:25 ]-[ "^A" : "^Z" ]+["A":200.4]      // интервалы
```

#### 4.e. Дополнительные форматы интервалов

Интервал может быть задан в формате средней точки и отклонения:
<pre>
  [средняя точка +- отклонение]
</pre> 
Например:
```
  X = [10 +- 0.1]               // интервал [9.9:10.1]
```
В качестве средней точки и отклонения могут указываться целые и вещественные числа (средняя точка, при необходимости, со знаком минус) и символы ASCII. Квадратные скобки могут быть опущены, а при задании интервала в тексте скрипта - должны быть опущены.\
Также для задания минимальной левой границы и максимальной правой может использоваться символ двоеточия. Например:
```
  X = [::0] + [0::]    // результат [-9223372036854775807:9223372036854775807]
```

#### 4.f. Физическая размерность
 
После числовых значений может быть указана физическая размерность величины. Физическая размерность должна быть отделена от последнего числа хотя бы пробелом. Например:
```
  X = [10+-2 m/s]  // результат [8:12] m/s
``` 
Замечание: при присвоении размерности значению в самой формуле она должна быть указана в обратных апострофах. Например:
```
  X = [10 +- 2]`m/s` + [3 +-1 km/h]
```

### 5. Функции-подпрограммы, определяемые в скрипте

#### 5.a. Определение функции-подпрограммы

В скрипте можно использовать функции-подпрограммы, определенные непосредственно в теле самого скрипта. Например:
```
  (  func ABC(A, B, C);
       A+B+C
     endfunc;

     ABC(10, 20, 30)  )
```
Функция-подпрограмма должна быть определена перед ее использованием. Функция-подпрограмма может быть определена в любом месте скрипта, где допустимо указывать выражение, в том числе, и внутри другой функции-подпрограммы, однако область видимости всех функций-подпрограмм - глобальная, независимо от места их определения.\
Функция-подпрограмма определяется как:
<pre>
  func <Имя>( <формальные параметры через [,;]> )[,;]
    одно или несколько выражений, разделенных [,;]
    результат функции-подпрограммы - результат последнего выражения
  endfunc
</pre>

#### 5.b. Локальные переменные в функции-подпрограмме

В функции-подпрограмме создается своя локальная область переменных. Для получения значения переменной или присваивания значения осуществляется иерархический поиск переменной от локальной области к глобальной. Для того, чтобы создать переменную (с возможностью её инициализации) в локальной области без поиска, служит функция `local()`. Например:
```
   (  func ABC(A, B, C);
         local(X, Y=10, Z=A);
         X=2;
         X+Y+Z+B+C
      endfunc;

      ABC(1, 2, 3)   )
```
Формальные переменные также создаются в локальной области.

#### 5.c. Параметры по умолчанию

В параметрах может быть указано значение по умолчанию, которое используется, если оно не передано при вызове. Например:
```
        (  func ABC(A, B=15, C=34+23);
              A+B+C
           endfunc;

           ABC(1)   )
```

### 6. Директивы

#### 6.a. Директива define

Директива `define <идентификатор> "текст"` - заменяет в формуле указанный идентификатор на текст. В идентификаторе допускаются буквы латинского алфавита, цифры, символ точки (за исключением первого символа), символ подчеркивания. Регистр символов не учитывается. Перед использованием в скрипте идентификатор должен быть определен. В подставляемом тексте также могут использоваться идентификаторы других определений. Например:
```
  define MySum " 2 plus 7 "
  define plus  ' + '
  MySum                        // результат 9
```

### 7. Функции

#### 7.a. Встроенные функции

RunFormula имеет предопределенный набор встроенных функций. Описание встроенных функций смотри далее. Также смотри описание функций, которые добавляют подключаемые модули в соответствующих файлах справок.

#### 7.b. Пользовательские функции

Имеется возможность зарегистрировать и использовать дополнительные пользовательские функции. Пользовательская функция должна быть глобальной и иметь следующий заголовок:
<pre>
  function(const ParamCount:SizeInt; Context:pointer; var Dim:SizeInt):Variant;
</pre>
ParamCount - количество переданных параметров;
Dim - закодированная размерность значения переменной (0 - если не используется);
Context - указатель, необходимый для получения значения параметров.
Тип результата пользовательской функции - Variant.

#### 7.c. Регистрация пользовательской функции

Пользовательская функция должна быть зарегистрирована с помощью функции `RunFlaFuncReg`. В функции `RunFlaFuncReg` `Name` - строка с именем функции, обязательно сточными символами, `Func` - указатель на пользовательскую функцию.\
При возникновении ошибки регистрации функция `RunFlaFuncReg` возвращает код ошибки из списка `TRunFlaErrCode`, либо `OK`, если ошибки нет. Также `RunFlaFuncReg` заносит код ошибки в глобальную переменную `RunFlaErrCode`, если ранее в ней не было другого кода ошибки.\
Регистрация требуется однократно после запуска программы до вызова функции `RunFlaParse` (и, соответственно, `RunFlaExecStr/RunFlaExecVrt`). Допускается многократная регистрация, регистрация с изменением адреса функции и перекрытие предопределенных функций. В случае перекрытия `RunFlaFuncReg` возвратит код ошибки `FuncExist`, но информация будет изменена.

#### 7.d. Получение значений параметров

Для получения значений параметров пользовательской функции служит функция `RunFlaParam`. В ней `Оffset` вычисляется как `<0-based номер требуемого параметра> - ParamCount`, `Context` должен быть передан из заголовка пользовательской функции.\
Замечание: значение параметра (в том числе и в случае предопределенной функции) вычисляется только при запросе его внутри самой функции.
`RunFlaParamAsStr` - функция возвращает параметр в виде строки.

#### 7.e. Пример пользовательской функции

```
  function MyIFFunc(const ParamCount:SizeInt; Context:pointer; var Dim:SizeInt):Variant;
  begin
    if ParamCount<>3 then RunFlaRaise(ParamNumber);     // проверка числа параметров
    if RunFlaParam(-3, Context)>0                       // тестируем первый параметр
      then Result:=RunFlaParam(-2, Context)             // если >0 возвращаем второй
      else Result:=RunFlaParam(-1, Context);            // если нет, то третий
  end;
```
регистрация с проверкой ошибки
```
  if RunFlaFuncReg('myiffunc', @MyIFFunc)<>OK then ShowMessage('Registration Error');
```
  теперь, если выполним скрипт
```
  ( X=10, Y=20, MyIfFunc(10, X+10, Y-20) )
```
  получим результат 20. При этом вычитание Y-20 выполнятся не будет.

### 8. Инициализация переменных во время выполнения скрипта

Значение переменной может быть присвоено во время выполнения скрипта с помощью обратного вызова внешней глобальной функции следующего типа:
<pre>
  function(constref Name:string; out Save:boolean; var Dim:SizeInt):Variant;
</pre>
Параметры функции:
  `Name` - имя (в нижнем регистре) запрашиваемой переменной;
  `Dim` - закодированная размерность значения переменной (0 - если не используется);
  `Save` = `True` - сохранить значение переменной в глобальном списке переменных и далее не запрашивать ее;

Например, определим такую глобальную функцию:
```
  function MyRunFlaVar(constref Name:string; out Save:boolean; var Dim:SizeInt):Variant;
  begin
    Result:=InputBox('', 'Get value for variable '+Name, '');
    Save:=false;
  end;
```
Укажем ее адрес в функции `RunFlaExecStr/RunFlaExecVrt`:
```
  ShowMessage( RunFlaExecStr(RunFlaParse('A & A'), Error, @MyRunFlaVar) );
```
О параметре `Error` смотрите раздел справки об обработке ошибок.
Результатом будет отображение строки, состоящей из двух объединенных введенных пользователем строк.

Внимание! Параметр Name имеет корректное значение только во время выполнения функции `RunFlaExecStr/RunFlaExecVrt`. Если значение `Name` необходимо и после, то его следует скопировать в новую строку, например, так:
```
  S:=Name;
  UniqueString(S);
```
или
```
  S:=StrPas(PChar(Name));
```

### 9. Обработка ошибок

#### 9.a. Структура TRunFlaError

Для получения информации об ошибке во время выполнения функций `RunFlaParse` и `RunFlaExecStr/RunFlaExecVrt` служит структура `TRunFlaError`, определенная в файле `runflaerr.inc`. В ней `Code` - код ошибки из списка `TRunFlaErrCode`, `Position` - позиция ошибки, начиная с 0, в тесте скрипта, `Value` - результат последней операции в виде текстовой строки, которая заполняется функциями `RunFlaExecStr/RunFlaExecVrt`. Переменная с типом `TRunFlaError` должна быть передана в функции `RunFlaParse` и `RunFlaExecStr/RunFlaExecVrt`. Функция `RunFlaParse` заполнит эту структуру информацией об ошибке. Если ошибки нет, то `Code` будет присвоен код OK, `Position` - 0. Функции `RunFlaExecStr/RunFlaExecVrt` заполняют структуру `TRunFlaError` при условии, что в ней не содержится информация об ошибке `(Code == OK)`.

#### 9.b. Глобальная переменная RunFlaErrCode

Код ошибки во время выполнения функций `RunFlaParse`, `RunFlaExecStr`, `RunFlaExecVrt` и `RunFlaFuncReg` также записывается в глобальную переменную `RunFlaErrCode`, но при условии, что в ней до этого не содержится информация об ошибке `(RunFlaErrCode == OK)`.

#### 7.c. Результаты функций RunFlaParse и RunFlaExecStr/RunFlaExecVrt при ошибке

При возникновении ошибки в функциях `RunFlaParse` и `RunFlaExecStr/RunFlaExecVrt` их результатом будет пустая строка. При передаче пустой строки в качестве параметра `Fla` в функции `RunFlaParse` и `RunFlaExecStr/RunFlaExecVrt` их результатом также будет пустая строка, но ошибка в этом случае не возникает.\
Замечание: Передача непустого, корректного, но не содержавшего скрипта параметра `Fla` в функцию `RunFlaParse` (например, содержавшего только комментарий) эквивалентно передаче константы `None` (пустая строка).

#### 9.d. Формирование ошибки пользователем

В функциях запроса значения переменной (`TRunFlaVar`) и дополнительных функциях, определенных пользователем (`TRunFlaFunc`), есть возможность прервать вычисление и сформировать ошибку с кодом из перечня `TRunFlaErrCode`. Для этого служит процедура `RunFlaRaise`. Например:
```
  function MySumFunc(const ParamCount:SizeInt; out Dim:SizeInt; Context:pointer):Variant;
  begin
    if ParamCount<>2 then RunFlaRaise(ParamNumber);          // проверка числа параметров
    Result:=RunFlaParam(-2, Context)+RunFlaParam(-1, Context);
  end;
```

#### 9.e. Текстовое сообщение об ошибке

Для преобразования кода ошибки в текстовое сообщение служит список `RunFlaErrorMsg`, определенный в файле `runflamsg.inc`. Например:
```
  procedure TForm1.ExecButtonClick(Sender: TObject);
  var Error : TRunFlaError;
  begin
    ShowMessage( RunFlaExecStr(RunFlaParse('9 * 3x', Error), Error) );
    ShowMessage( RunFlaErrorMsg[Error.Code].ErrMsg + ' at: ' + IntToStr( Error.Position ) +' "'+Error.Value+'"');
  end;
```
Этот список и файл может быть заменен пользователем.

9.f. Рекомендуется отключить генерацию exception в MemGet

### 10. Запуск байт-кода

Результат функции `RunFlaParse` (байт-код) может быть сохранен, а функции `RunFlaExecStr/RunFlaExecVrt` могут быть многократно вызваны с ним без предварительного вызова `RunFlaParse`. При этом требуется соблюдение следующих условий:
  - пользовательские функции должны быть зарегистрированы в том объеме и том порядке, который был до вызова `RunFlaParse`;
  - для получения информации об ошибке поле `TRunFlaError.Code` и глобальная переменная `RunFlaErrCode` должна быть  инициализирована как `OK`;
  - если изменился исходный код RunFormula, то `RunFlaParse` должна быть выполнена заново.

### 11. Встроенные функции

Все функции, за исключением оговоренных случаев, поддерживают все допустимые типы параметров.

#### 11.a. Функции управления потоком выполнения

`result([результат])` - прерывает выполнение скрипта и возвращает заданный результат. Если результат не задан, то результат скрипта равен None.

`exit([результат])` - досрочный выход из функции с заданным результатом. Если результат не задан, то результат функции равен None. Если функция вызывается в глобальном блоке, то производится выход из скрипта.

`break([результат])` - досрочный выход из цикла. Может быть задан необязательный результат функции цикла.

`continue()` - досрочная итерация цикла

`if(<условие>, <параметр 1> [, параметр 2])` - если условие выполнено (равно True), то возвращает значение параметра 1. Если условие не выполнено (равно False), то возвращает значение параметра 2, если он задан, либо None.

`repeat(<условие>, <параметр>)` - повторяет запрос значения параметра, пока выполняется условие (равно True). Возвращает значение параметра, либо None, если ни одного цикла не было.

`type(<параметр>)` - возвращает целое число, соответствующее типу параметра:
<pre>
    0 - нет значения, пустая строка, None
    1 - целое число
    2 - вещественное число
    3 - зарезервировано
    4 - комплексное число
    5 - символ ASCII
    6 - строка
    7 - интервал
    8 - интервал с целыми границами
    9 - зарезервировано для массива
</pre>

#### 11.b. Математические функции

`sqrt(<аргумент>)` - возвращает квадратный корень аргумента

`exp(<аргумент>)` - возвращает экспоненту заданного аргумента

`pow(<основание>, <показатель степени>)` - возводит основание в заданную степень

`ln(<аргумент>)` - возвращает натуральный логарифм аргумента

`log(<аргумент>, <основание>)` - возвращает логарифм аргумента по заданному основанию

`sin(<аргумент>)` - возвращает синус аргумента

`cos(<аргумент>)` - возвращает косинус аргумента

`tan(<аргумент>)` - возвращает тангенс аргумента

`arctan(<аргумент>)` - возвращает арктангенс аргумента

`abs(<аргумент>)` - возвращает абсолютное значение аргумента. Для комплексного числа возвращает его модуль. Для интервала возвращает интервал абсолютных значений всех его чисел. Для символа ASCII возвращает его код.

#### 11.c. Функции для работы с комплексными числами

`re(<комплексное число>)` - возвращает действительную часть комплексного числа

`im(<комплексное число>)` - возвращает мнимую часть комплексного числа

`cplex(<действительная часть>, <мнимая часть>)` - возвращает комплексное число, сформированное по заданной действительной и мнимой части

`arg(<комплексное число>)` - возвращает безразмерный аргумент (фазу) комплексного числа. Модуль (абсолютное значение) комплексного числа можно получить с помощью функции abs().

`conj(<комплексное число>)` - возвращает комплексно-сопряженное число

`rect(<модуль>, <аргумент>)` - возвращает комплексное число, сформированное по заданному модулю и аргументу (фазе). Аргумент должен быть безразмерным.

#### 11.d. Функции для работы с интервалами

`left(<интервал>)` - возвращает левую границу интервала

`right(<интервал>)` - возвращает правую границу интервала

`range(<левая граница>, <правая граница>)` - возвращает интервал, сформированный по заданной левой и правой границе. Левая граница должна быть меньше или равна правой.

`ball(<середина>, <полуширина>)` - возвращает интервал, сформированный по заданной середине и полуширине (отклонению от середины)

`margin(<интервал>)` - возвращает полуширину (отклонение от середины) интервала. Середину интервала можно получить с помощью функции re(), например:
```
    X = [10:20]; re(X) & "+-" & margin(X)    // результат 15+-5
```

#### 11.e. Функции округления

`frac(<аргумент>)` - возвращает дробную часть аргумента. Дробная часть всегда положительна и вычисляется как математическая дробная часть числа, т.е. как разность между числом и его округлением к меньшему. Для комплексных чисел дробная часть вычисляется отдельно для действительной и мнимой части. Для целых чисел и символов ASCII возвращает вещественный 0. Для интервалов функция не допустима. Например:
```
  X = frac(1.3)    // результат 0.3
  X = frac(-1.3)   // результат 0.7
```

`trunc(<аргумент>)` - возвращает целую часть аргумента. Для комплексных чисел и интервалов целая часть вычисляется отдельно для действительной и мнимой части и границ интервала. При возможности, преобразует тип результата к целому числу и интервалу с целыми границами.

`floor(<аргумент>)` - округляет аргумент до ближайшего меньшего целого числа. Для комплексных чисел и интервалов округление выполняется отдельно для действительной и мнимой части и границ интервала.

`ceil(<аргумент>)` - округляет аргумент до ближайшего большего целого числа. Для комплексных чисел и интервалов округление выполняется отдельно для действительной и мнимой части и границ интервала.

`round(<аргумент>)` - округляет аргумент. Производится математическое округление к ближайшему целому числу. Для интервала левая граница округляется вниз, правая вверх. Комплексные числа округляются в полярных координатах, фаза (аргумент) комплексного числа округляется в градусах.

#### 11.e. Функции для работы со строками и символами ASCII

`length(<строка>)` - возвращает длину строки в байтах

`string(<параметр>)` - преобразует параметр в строку (эквивалентно
<параметр> & "")

`find(<строка>, <шаблон>, [смещение])` - ищет шаблон в строке и возвращает позицию его начала. Если задан необязательный положительный параметр [смещение], то поиск начинается с позиции, заданной этим параметром. Сравнение строки с шаблоном побайтовое (с учетом регистра символов). Смещение и результат отсчитываются начиная с 0 от начала строки. Если шаблон не найден, то возвращает -1. Если строка или шаблон пустые или смещение больше или равно длине строки, то возвращает -1.

`substr(<строка>, <интервал>)` - возвращает участок строки, позиции начала и конца которого заданы интервалом. Интервал целочисленный. Позиции в строке отсчитываются начиная с 0. Если левая или правая границы интервала лежат вне строки, то они приводятся к началу или концу строки соответственно. Если интервал полностью лежит вне строки, то возвращает None. Если возвращаемое значение является единственным символом, то он возвращается как тип символа ASCII.

`val(<строка>)` - преобразует строку, заданную в едином числовом формате, в числовое значение

`char(<целое число>)` - выделяет младший байт целого числа и преобразует его в символ ASCII. Код символа ASCII можно получить с помощью функции abs().

`hexstr(<целое число>)` - преобразует целое число в его текстовое представление в шестнадцатеричном виде

#### 11.e. Функции сравнения

`compare(<аргумент 1>, <аргумент 2>)` - сравнивает аргументы, возвращает -1 0 +1

`sign(<параметр>)` - возвращает значения -1, 0, +1 в соответствии со знаком параметра.
<pre>
    - для None возвращает 0
    - для комплексного числа результат -1 или +1 определяется по действительной части. Если действительная часть равна 0, то по мнимой части. Если действительная и мнимая части равны 0, то возвращает 0.
    - для строки возвращает +1, если ее длина больше нуля, иначе возвращает 0
    - для символа ASCII возвращает 0, если его код равен 0 ("^@"), иначе возвращает +1
    - для интервала возвращает 0, если число 0 входит в интервал, иначе результат +1 или -1 определяется левой границей
</pre>

#### 11.f. Функции для работы с физическими размерностями

`match((<параметр 1>, <параметр 2>)` - сравнивает размерности параметров, возвращает -1 (True), если параметры имеют одинаковые размерности, иначе возвращает 0 (False)

`qty(<параметр>, <размерность>)` - присваивает безразмерному параметру размерность, заданную в виде строки. При необходимости производится преобразование параметра в соответствии с заданной размерностью. Например:
```
  qty(20, "degC")        // результат 293.15 K
```

`conv(<параметр>, <размерность>)` - преобразует параметр, имеющий размерность, в безразмерное значение. При необходимости производится преобразование параметра в соответствии с заданной размерностью. Например:
```
  conv(293.15 `K`, "degC")      // результат 20
```

`unitstr(<параметр>)` - возвращает размерность параметра в виде строки. Если параметр не имеет размерности, то возвращает None.
