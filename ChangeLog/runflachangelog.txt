===== Version 0.0 - 9.05.2026 =====
- First RunFormula release

===== Version 0.1.b - 1.06.2026 =====
- Changed: Error message structure is updated
- Changed: In external function parameter Phy is renamed to Dim
- Added: Physical dimension handling
- Changed: Char value is converted to a Variant of type byte

===== Version 0.2 - 23.07.2026 =====
- Fixed: Incorrect error position in qtx() function
- Added: New embedded functions - margin(), ball(), arg(), conj(), rect(), floor(),
ceil(), find(), substr(), hexstr(), unitstr()
- Changed: Embedded functions logic (detailed in help) - frac(), trunc()
- Removed: Embedded function - int()
- Added: New constant - MaxInt
- Added: New error codes - RangeType, CommaDigit, InvalidType
- Changed: Digit is not allowed immediately after a comma or semicolon, space or
separator required
- Fixed: Decimal separator is always a dot, regardless of system locale
- Added: CGS and Astronomical units of measurement
- Fixed: Memory access violation caused by certain errors
- Added: Syntax validation for brackets in unit expressions
- Added: New inteface function - RunFlaParamAsStr
- Changed: Dimensions are passed by reference in interface functions
- Changed: Number-to-string and string-to-number conversion use a Unified
numeric format without backticks for units

===== Version 0.2a - 1.08.2026 =====
- Added: The ASCII character with code 0x7 can be used to define a string
- Added: New embedded functions - pow(), log(), tan()

===== Develop branch changes =====
- Changed: Embedded function value() is renamed to val()
